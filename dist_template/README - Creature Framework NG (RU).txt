Creature Framework NG 4.1
=========================

Нативная SKSE-переработка Creature Framework 4.0 для Skyrim Special Edition / Anniversary Edition.
Всё, что Creature Framework делал на Papyrus, — поиск существ, решение о возбуждении, смена тел,
снятие и возврат снаряжения — теперь выполняется внутри CreatureFrameworkNG.dll.
MCM, JSON-регистрации в Data\creatures.d и API скриптов остались прежними, поэтому
More Nasty Critters и другие моды на существ работают без изменений.

Это полноценная замена: в архиве есть CreatureFramework.esm и все скрипты.
НЕ устанавливайте оригинальный Creature Framework вместе с ним.


Требования
----------
- Skyrim SE 1.5.97 или AE 1.6.x
- SKSE64
- Address Library for SKSE Plugins
- JContainers SE
- SkyUI (MCM)
- По желанию: SexLab Framework / SexLab P+, SexLab Aroused или OSL Aroused


Установка
---------
1. Удалите или отключите оригинальный Creature Framework.
2. Установите архив через менеджер модов.
3. CreatureFramework.esm оставьте на месте оригинала в порядке загрузки.
4. Старые сохранения: загрузитесь и подождите ~10 секунд, пока Creature Framework
   инициализируется. Выбор активных модов в MCM и снаряжение, снятое старой версией,
   переносятся автоматически.


Отличия от Creature Framework 4.0
---------------------------------
Производительность
- Больше нет квеста-«плаща», который перезапускался каждые 15 секунд, и циклов с Utility.Wait;
  существа рядом проверяются нативно раз в секунду почти без затрат.
- Creature Framework больше не занимает виртуальную машину Papyrus, другие скриптовые моды
  не ждут в очереди.
- Тела меняются сразу при подготовке сцены SexLab и возвращаются примерно через секунду после конца.

Исправленные баги 4.0
- Оружие, снятое на сцену, никогда не возвращалось (вместо оружия надевался сам актёр).
  Теперь возвращается после сцены.
- Просто возбуждённые существа теряли оружие вне сцен. Теперь снаряжение снимается только в сценах SexLab.
- Кнопка «по умолчанию» у существа в MCM его не отключала.
- Регистрации типа «смена брони и события» никогда не меняли броню.
- Отмена регистрации мода могла стереть другой мод из списков рас и кож.
- Обработчик экспозиции SexLab Aroused никогда не обрабатывал существ.

Плагин
- Form version 44 во всех записях (в 4.0 была form 43).
- Удалены пять копий ванильных записей из Skyrim LE (MudcrabRace, MQ101Alduin, MQ206AncientAlduin,
  MQ101Horse, MQ101CartHorse), которые откатывали данные Special Edition. Они были нужны только
  ради ключевого слова CFIgnoreThisCreature — теперь его добавляет DLL при загрузке игры.

Поведение
- Порог возбуждения по умолчанию 70 вместо 35. С OSL Aroused большинство существ держатся выше 35
  и были возбуждены постоянно. Сохранения со старым значением 35 один раз переводятся на 70.
- JSON-регистрации перечитываются при каждом запуске игры, так что изменения в JSON применяются.


Настройки
---------
MCM > Creature Framework: те же страницы, что в 4.0. Ползунок «Cloak cooldown» больше ни на что не влияет.
Data\SKSE\Plugins\CreatureFrameworkNG.ini: интервал проверки и подробный лог.
